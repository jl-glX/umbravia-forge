UMBRAVIA FORGE - PAQUETE DE PRUEBA PARA WINDOWS
================================================

Este ZIP prepara el acceso web de:

- Umbravia Forge: aplicación principal y comercial.

Requisitos:

- Windows 10 u 11 con Microsoft Edge instalado.
- Conexión a Internet.
- Una cuenta autorizada para la aplicación elegida.

Instalación:

1. Extrae todo el ZIP en una carpeta nueva.
2. Comprueba SHA256SUMS.txt si el archivo procede de una descarga.
3. Ejecuta Instalar-Umbravia-Forge.cmd.
4. El instalador abre la aplicación y mantiene la ventana visible hasta que
   confirmes el resultado. Después puedes usar el acceso creado en el
   escritorio o en el menú Inicio.

Si aparece el aviso de que faltan archivos, se está ejecutando directamente
desde el visor del ZIP o se ha extraído solo el CMD. Extrae siempre el contenido
completo en una carpeta antes de instalar.

Desinstalación:

Ejecuta Desinstalar-Umbravia-Forge.cmd para retirar la aplicación principal.
No borra cuentas ni datos del servidor.

Alcance de esta primera prueba:

- Es un lanzador web instalado, no una aplicación nativa ni un cliente sin
  conexión.
- No incluye servidor, base de datos, secretos, contraseñas ni sesiones.
- Microsoft Edge conserva su propia sesión y aplica las políticas del equipo.
- El paquete no está firmado todavía. Los envoltorios limitan la excepción de
  ejecución al proceso que abre el script incluido; revisa el hash antes de
  ejecutarlo.
- La instalación real debe probarse con validación humana en un equipo Windows
  limpio antes de anunciarla como distribución estable.
